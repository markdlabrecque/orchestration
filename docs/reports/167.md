# Ticket #167 report: Control envelope

## Delivered

Added the `orch.control/1` JSON request/response envelope over stdin/stdout. `src/control.ts` validates requests and returns `invalid-request`, `unsupported-version` (supported majors `[1]`), or `unsupported-op` errors; the `capabilities` operation is accepted. `src/cli.ts` adds the `control` command and injectable/default stdin, and handles `--json` before or after commands while preserving a literal `--json` value after `--owner-lifetime`. Documented control requests in `docs/v2/usage.md`; added about 57 tests in `test/control.test.ts`.

The first implementation was in Python on `main`, the wrong base; it was discarded after rebasing onto `v2` and redone in TypeScript. Durability remains unqualified (#157).
