# Ticket 122: Expose this orchestration to Claude Desktop as well

Issue: https://github.com/markdlabrecque/orchestration/issues/122

Desktop often has `start_session` gated ("Starting sessions is not enabled here."). Before this change, `orch spawn/resume --platform desktop` only printed `desktop_start` / `desktop_resume` actions that needed it, so Desktop could not host ticket sessions.

## Verified premises

Probed on Claude Code 2.1.296, macOS, 2026-10-13:

- `claude --bg --name <n> "<prompt>"` works. It ignores `--session-id`, so the session id must be read back.
- `claude agents --json --all` lists bg sessions with a short `id` and a full `sessionId` (UUID).
- `--bg` refuses an untrusted folder, so the worktree is marked trusted first.
- `claude stop <shortid>` exits 0 and is idempotent.
- `claude --desktop --resume <uuid>` refuses redirected stdio. Under a pty (`script -q /dev/null`) it exits 0 and the session appears in the Desktop sidebar.
- `--desktop` refuses a prompt. The brief must be sent from the main session with `SendMessage`. This was verified live: a probe session in the Desktop sidebar received the message and replied.

## Delivered

- `orch spawn` and `orch resume` accept `--desktop-cli` (or `ORCH_DESKTOP_CLI=1`) with `--platform desktop`. The flag is Claude-only; other harnesses are refused.
- With the flag, orch marks the worktree trusted, runs `claude --bg --name t<ticket> <claude_args> "<short prompt>"`, reads the full session id from `claude agents --json --all`, stops the bg session, and opens it in Desktop with `script -q /dev/null claude --desktop --resume <sid>`.
- The session is recorded the same way `orch attach` records it. orch prints a `desktop_send` action with the ref, name, cwd, and prompt file. The main session sends the brief with `SendMessage`.
- Resume with a UUID ref reopens that session. A non-UUID ref falls back to a full start.
- Any failure after `--bg` stops the bg session and restores ticket state.
- Without the flag, desktop behaviour is unchanged.

Changed files: `scripts/orch`, `tests/test_orch_platforms.py`, `skills/orchestration/SKILL.md`, `skills/orchestration/references/platforms.md`, `skills/orchestration/references/orch-cli.md`, `README.md`. See `git diff` in the worktree. Spec: `orch-scratch/spec.md`.
