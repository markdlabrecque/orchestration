## What was built

- `scripts/orch` now permits three successful review/verify-to-fix bounces, shared through durable B, and two independent successful CI-to-fix repairs through durable C. R remains unlimited review-entry history. New tickets start with B=C=0.
- Retired/legal-edge checks precede budget checks. Review budget exhaustion precedes the frontier/high gate. Successful phase, counter and event writes commit together under `BEGIN IMMEDIATE`; refusals exit 3 without mutation. Refusal does not automatically block. The orchestrator must retain findings and explicitly block for a human before further repair dispatch.
- Escalation, new agents, process reopening, resume/attach, block/unblock and other phase edges never replenish budgets. Routes and run records consume neither budget. Existing run bounce snapshots remain intact. Unknown B refuses run recording before insertion rather than crashing or inventing a zero snapshot.
- Transactional, idempotent migration reconstructs missing counts from successful phase events and preserves existing and over-cap counts. Inspection exposes both counts, with JSON `null` for durable unknown history.
- `orch-cli.md` and `ticket-pipeline.md` document the implemented budgets, successful phase-before-dispatch requirement, explicit human stop and reason-specific exit-3 handling.

Migration checks require the creation event, a continuous recorded phase chain and agreement with the current terminal phase. They detect missing creation/interior events and terminal mismatches, but cannot detect every historical loss, including deletion of a complete round trip. Unknowns require evidence-backed human reconciliation of the actual count under separately authorized maintenance, with supporting records retained. There is no reset, override or reconciliation command, and initialized counts are not recomputed downward.

Sibling intent remains intact: ticket 8's real heavy-review-fix to standard/low CI regression, ticket 26's phase-before-dispatch/frontier distinction, routing defaults and floors, effort-first escalation, resumed-agent identity accounting, ready-phase dispatch guidance, model defaults and readiness regressions.
