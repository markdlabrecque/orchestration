# Ticket 109 report: Triage the bounce cap stop into a clear choice

Issue: https://github.com/markdlabrecque/orchestration/issues/109

## Result

When `orch phase <t> fix` from `review` or `verify` is refused because the bounce budget is exhausted (`bounces >= BOUNCE_CAP` with no matching repair grant), `orch` now runs a read-only triage before raising the refusal.

- `bounce_triage()` in `scripts/orch` reads the ticket's findings ledger and picks one case by fixed rules, first match wins. Only must-fix findings count.
  1. `disagreement`: any must-fix finding is `disputed`.
  2. `recurring-finding`: any open must-fix with `rounds_open >= 2`.
  3. `unclear-or-oversized`: at least half of the must-fix findings are `deferred` or have no file. After round 1 this rule is limited to non-fixed findings.
  4. `moving-target`: anything else with a usable ledger.
- It writes `<state dir>/triage/<ticket>.md`, overwriting any existing file. The file has no timestamps, so the same ledger gives byte-identical content. It holds the stop, the case and its signal, a recommended option, one other option, a how-to-answer line, an "Also available" line offering parking as a draft PR (`orch park`, #110), and the must-fix ledger table.
- With no usable ledger (no findings, or no must-fix findings), no file is written. The refusal says `triage: no findings ledger` and keeps the old block advice.
- The refusal branch in `cmd_phase` still exits 3 with the budget-exhausted message. It now names the case and the triage path, and the suggested block command carries them: `orch block <t> --reason "bounces budget exhausted (3/3); triage: <path>; findings: <link>"`.
- Triage changes no database state: no event, counter, phase change, or grant. It does not consume a bounce, grant a repair, or bypass the frontier gate. Unknown-history, frontier/high, and `ci -> fix` refusals are unchanged.

Docs:

- `skills/orchestration/references/ticket-pipeline.md`: new "Bounce cap triage" subsection with the ordered rules table, file location, block-reason form, and the no-grant guarantee.
- `skills/orchestration/references/orch-cli.md`: paragraph where the budget refusal is described.
